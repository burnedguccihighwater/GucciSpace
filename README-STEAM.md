# Gucci Space: Steam

Профиль: https://steamcommunity.com/id/bleed4gucci/

SteamID64: `76561198855975484`.

Раздел Games получает всю библиотеку через официальный `IPlayerService/GetOwnedGames`, включая бесплатные игры, в которые пользователь играл. Обложки загружаются с CDN Steam. Поиск и сортировка работают по всей полученной библиотеке; кнопка «Показать ещё» раскрывает остальные карточки по 12.

## Подключение

1. Открой https://steamcommunity.com/dev/apikey в своём аккаунте Steam. Используй существующий ключ или зарегистрируй ключ для домена `gucci-space.vercel.app`.
2. В Vercel открой проект **gucci-space → Settings → Environment Variables**. Добавь переменную `STEAM_API_KEY` со значением ключа для **Production**. Сам ключ хранится только в настройках сервера.
3. Выполни **Redeploy** последней версии проекта, чтобы применить переменную.
4. В настройках приватности Steam открой профиль и «Доступ к игровой информации». Если хочешь показывать часы, отключи скрытие общего времени в играх.

Синхронизация выполняется при открытии сайта и каждые 5 минут, пока вкладка видима. Серверный кэш обновляется не чаще раза в 5 минут. Обновления не требуют нового коммита или ручного списка игр.

`/api/steam` возвращает состояние `not_configured`, пока ключ не добавлен. Закрытая библиотека, ошибка ключа и временная недоступность Steam отображаются отдельно. При временной ошибке ранее загруженные игры остаются на странице. Скрытые часы не считаются нулевыми. Ключ, cookies и логин Steam посетителям не передаются.

## Проверка

`npm test` проверяет полный импорт, скрытые часы, ошибки доступа, поиск, сортировку и серверный маршрут. API не принимает произвольные SteamID и не может использоваться как прокси к чужим профилям.
