# Gucci Space: Steam

Профиль: https://steamcommunity.com/id/bleed4gucci/

SteamID64: `76561198855975484`.

Раздел Games получает всю библиотеку через официальный `IPlayerService/GetOwnedGames`, включая бесплатные игры, в которые пользователь играл. Программы исключаются по официальному каталогу `IStoreService/GetAppList` с `include_software=true` и `include_games=false`. Каталог загружается полностью с продолжением по `last_appid` и кэшируется на сервере на 6 часов. Число игр и общее время пересчитываются после исключения программ.

На странице остаются два счётчика и непрерывная горизонтальная витрина с обложками всех игр. Пагинации, поиска и фильтров нет. Витрина движется со скоростью 32 пикселя в секунду, позволяет ручную прокрутку и свайпы, останавливается при наведении или клавиатурном фокусе. За пределами экрана, в фоновой вкладке и при включённом уменьшении движения автопрокрутка останавливается. Обложки загружаются с CDN Steam по мере приближения. Обычное обновление данных не перезапускает цикл витрины.

## Подключение

1. Открой https://steamcommunity.com/dev/apikey в своём аккаунте Steam. Используй существующий ключ или зарегистрируй ключ для домена `gucci-space.vercel.app`.
2. В Vercel открой проект **gucci-space → Settings → Environment Variables**. Добавь переменную `STEAM_API_KEY` со значением ключа для **Production**. Сам ключ хранится только в настройках сервера.
3. Выполни **Redeploy** последней версии проекта, чтобы применить переменную.
4. В настройках приватности Steam открой профиль и «Доступ к игровой информации». Если хочешь показывать часы, отключи скрытие общего времени в играх.

Синхронизация выполняется при открытии сайта и каждые 5 минут, пока вкладка видима. Серверный кэш обновляется не чаще раза в 5 минут. Обновления не требуют нового коммита или ручного списка игр.

`/api/steam` возвращает состояние `not_configured`, пока ключ не добавлен. Закрытая библиотека, ошибка ключа и временная недоступность Steam отображаются отдельно. При временной ошибке ранее загруженные игры остаются на странице. Скрытые часы не считаются нулевыми. Ключ, cookies и логин Steam посетителям не передаются.

## Проверка

`npm test` проверяет полный импорт, исключение программ из списка и времени, скрытые часы, многостраничный каталог программ, ошибки доступа, замыкание витрины и серверный маршрут. API не принимает произвольные SteamID и не может использоваться как прокси к чужим профилям.
