# Telegram profile sync
In Vercel project Settings > Environment Variables set a newly issued TELEGRAM_BOT_TOKEN (secret) and TELEGRAM_USER_ID (your numeric Telegram user ID), for Production. Start the bot from your own account first. Redeploy the latest commit. Keep secrets out of GitHub. Only the configured owner's profile is queried. The public endpoint returns up to 10 track titles, artists and durations and a proxied profile photo, never the Telegram token or ID. Bio sharing is off by default; set TELEGRAM_SYNC_BIO=1 only if desired. Browser-local manual avatar takes precedence; the bundled profile photo remains the fallback. /api/telegram returns 503 until configured or if Telegram is unavailable. No audio files are streamed.
